Первая версия с обновлением из приложения.

- На главном экране появилась строка «Обновление»: проверяет новую версию, скачивает APK и запускает обычный установщик Android. Профиль и настройки остаются на месте.
- APK теперь подписан своим ключом вместо debug-подписки, поэтому обновления смогут ставиться поверх друг друга.
- Релизы собираются автоматически на GitHub и публикуются вместе с манифестом обновлений.
