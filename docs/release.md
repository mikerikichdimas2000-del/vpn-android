# Как выпустить обновление

Короткий чек-лист. Всё, что делает CI, — собирает и публикует; руками правится только версия.

## 1. Поднять версию

В `app/build.gradle.kts`:

```kotlin
versionCode = 7          // +1 к предыдущему, обязательно
versionName = "0.4.1"    // то, что увидит пользователь
```

`versionCode` — единственное, что сравнивает приложение. Если забыть поднять,
телефоны решат, что обновления нет.

## 2. Написать, что нового

Файл `docs/release-notes/<versionName>.md`. Если его нет, в релиз попадёт
«Версия <versionName>», а в диалоге обновления будет пусто. Одна-две строки
по-человечески, без «улучшена стабильность».

## 3. Проверить локально

```powershell
.\gradlew.bat --no-daemon assembleDebug
.\gradlew.bat --no-daemon assembleRelease
```

`signing.properties` должен лежать рядом с проектом — иначе release соберётся
неподписанным, и CI упадёт на шаге проверки подписи.

## 4. Тег и пуш

```powershell
git add -A
git commit -m "0.4.1: что поменялось"
git tag v0.4.1
git push origin main --tags
```

Тег `v*` запускает `.github/workflows/release.yml`. Тот же workflow можно
запустить руками: Actions → release → Run workflow.

## 5. Что должно получиться

- в Actions зелёный прогон;
- в Releases — «VPN 0.4.1» с ассетами `vpn-0.4.1.apk` и `latest.json`, помеченный latest;
- `https://github.com/mikerikichdimas2000-del/vpn-android/releases/latest/download/latest.json`
  отдаёт новый `versionCode`.

## 6. Проверка обновления на телефоне

Ставим на устройство предыдущую версию, открываем приложение → «Обновление».
Должно быть: «Доступно обновление 0.4.1» → «Скачать и установить» → системный
экран установки → приложение перезапускается уже новым, профиль на месте.

## Если что-то сломалось

| Симптом | Причина |
|---|---|
| В приложении «Не удалось проверить обновления» | нет релиза, нет ассета `latest.json`, или релиз не помечен latest |
| «Файл повреждён: контрольная сумма не совпала» | APK пересобрали после генерации `latest.json` |
| «Подпись не совпала — обновление отклонено» | APK подписан не тем ключом: проверь секреты `KEYSTORE_*` |
| Установка не начинается, ошибки нет | не выдано разрешение «Установка неизвестных приложений» |
| После установки открылась старая версия | `versionCode` в APK не больше текущего |

## Секреты репозитория

`Settings → Secrets and variables → Actions`:

| Секрет | Что внутри |
|---|---|
| `KEYSTORE_BASE64` | `vpn-release.jks` в base64 без переводов строк |
| `KEYSTORE_PASSWORD` | пароль хранилища |
| `KEY_ALIAS` | `vpn` |
| `KEY_PASSWORD` | пароль ключа |

Файл `vpn-release.jks.b64` рядом с самим ключом — исходник для первого секрета.
